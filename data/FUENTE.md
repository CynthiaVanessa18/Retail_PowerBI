# Fuente de los datos

Chen, D. (2015). **Online Retail** [Dataset]. UCI Machine Learning Repository.

- Fuente: https://archive.ics.uci.edu/dataset/352/online%2Bretail
- DOI: https://doi.org/10.24432/C5BW33
- Licencia: [Creative Commons Attribution 4.0 International (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/).
- Archivo: `Online Retail.xlsx`, redistribuido sin modificaciones.

El informe transforma los tipos de datos y añade columnas y medidas para el análisis. Los datos corresponden a una empresa británica de comercio electrónico cuyo nombre no identifica la fuente. La referencia cromática no implica relación con Coca-Cola.
